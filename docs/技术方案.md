# Quik — 自定义按钮一键执行工具 技术方案

> 版本：v0.4｜日期：2026-10-13
> 目标：一个跨平台桌面客户端，用户可自定义"功能按钮"，按钮绑定 curl 脚本或任意命令，点击即执行，支持按钮名称/颜色自定义与分组管理。
>
> 📌 需求与开发进度跟踪见 [需求清单.md](./需求清单.md)（每条需求的完成状态以该文档为准）。

---

## 1. 需求梳理

| 需求 | 说明 | 优先级 |
|---|---|---|
| 按钮管理 | 新建/编辑/删除按钮，可改名称、颜色、图标 | P0 |
| 分组管理 | 按钮按类别（分组）归档，分组可增删改、排序 | P0 |
| curl 执行 | 按钮绑定 curl 脚本，点击一键执行 | P0 |
| **任意命令执行** | 除 curl 外支持任意 shell 命令/脚本（V1 即抽象动作类型） | P0 |
| 结果展示 | 实时显示 stdout/stderr、退出码、耗时 | P0 |
| 配置持久化 | 所有配置保存在本地，重启不丢 | P0 |
| 跨平台 | Windows / macOS / Linux 都要支持 | P0 |
| 配置导入导出 | **V1 留入口**：菜单提供导出/导入 `.quik.json`，格式为后续团队共享设计 | P1 |
| 执行确认 | 危险操作可配置"执行前弹窗确认" | P1 |
| 环境变量 | dev/prod 多环境，URL/Token 等占位符替换 | P1 |
| 执行历史 | 保留最近 N 次执行记录，可回看输出 | P1 |
| 系统托盘 + 全局快捷键 | 最小化到托盘、全局快捷键唤起主窗口 | P1 |
| 配置团队共享 | 合并导入、冲突处理（导入导出入口 V1 先留好） | P2 |
| 按钮批量编排 | 一个按钮按顺序执行多个动作 | P2 |

**已确认的决策**（2026-10-13 与需求方确认）：
1. 需要 Windows + macOS + Linux 三端支持。
2. 近期就需要执行任意命令，V1 起动作类型抽象为 `action.type`（curl / shell 并存）。
3. 团队共享暂不做，但导入导出入口和数据格式 V1 就留好。
4. 需要系统托盘与全局快捷键。
5. 后续会持续追加需求，统一登记进 [需求清单.md](./需求清单.md) 跟踪状态。

## 2. 技术选型（✅ 已确认：Tauri 2 + Vue 3，2026-10-13）

对比过的备选：

| 方案 | 安装包体积 | 内存占用 | 开发效率 | 跨平台 | 备注 |
|---|---|---|---|---|---|
| **Tauri 2 + Vue 3（已采用）** | ~10 MB | 低（复用系统 WebView） | 高 | ✅ Win/macOS/Linux | Rust 后端执行命令 |
| Electron + Vue 3 | ~80–150 MB | 较高 | 高 | ✅ | 纯 JS 技术栈，Node child_process |
| Flutter Desktop | ~20 MB | 中 | 中 | ✅ | Dart 技术栈，桌面生态偏弱 |

**采用 Tauri 2 + Vue 3 + TypeScript**，理由：
1. 常驻型小工具对体积和内存敏感，Tauri 明显优于 Electron。
2. 三端支持一套代码：Windows 用 WebView2、macOS 用 WKWebView、Linux 用 webkitgtk（主流发行版自带或一条命令安装）。
3. 前后端天然分离：前端只做 UI 与配置编辑，命令执行全部在后端（Rust）完成。
4. **托盘与全局快捷键是 Tauri 2 内置/官方插件能力**（tray-icon、global-shortcut），实现成本低。
5. curl 三端均可依赖系统自带（Win10 1803+ / macOS / Linux），无需打包。
6. 若后续想换 Electron，前端代码几乎原样复用，切换成本低。

跨平台分发注意：macOS 需要 Apple 开发者签名/公证才能免"未知开发者"提示（个人使用可右键打开或自签）；Linux 提供 AppImage/deb 双格式即可覆盖大多数场景。

## 3. 总体架构

```
┌─────────────────────────────────────────────────┐
│  前端 (Vue 3 + TS, 系统 WebView)                  │
│  ├─ 分组侧边栏 / 按钮网格 / 编辑弹窗 / 输出面板    │
│  └─ 状态管理 Pinia（分组、按钮、运行状态）         │
└───────────────┬─────────────────────────────────┘
                │ Tauri command / event (IPC)
┌───────────────┴─────────────────────────────────┐
│  后端 (Rust, tauri)                               │
│  ├─ 配置服务：读写 config.json（原子写入+备份）    │
│  │   └─ 导入/导出 .quik.json（V1 入口）           │
│  ├─ 执行器：spawn 子进程跑 curl/shell 脚本         │
│  │   └─ stdout/stderr 流式回传 event              │
│  ├─ 环境变量渲染：{{placeholder}} 替换            │
│  └─ 托盘 / 全局快捷键（tauri 内置能力）           │
└───────────────┬─────────────────────────────────┘
                │
        本地文件（各 OS 标准应用数据目录，由 Tauri 提供）
        ├─ config.json        # 分组+按钮+环境配置
        └─ history/*.json     # 执行历史（P1）
```

关键点：
- **执行流式输出**：子进程 stdout/stderr 按 chunk 通过 Tauri event 推给前端，输出面板实时滚动；退出后回传 exit code 与耗时。
- **并发控制**：同一按钮默认不允许重复并发执行（执行中置灰），后续可放开为"允许多实例"。
- **跨平台 shell 策略**：见 §7 风险第 1 条。

## 4. 数据模型（config.json）

```jsonc
{
  "version": 1,
  "settings": {
    "language": "zh-CN",        // 界面语言 zh-CN | en-US（vue-i18n）
    "defaultShell": "auto",     // auto | bash | cmd | powershell；auto 按检测顺序取第一个可用的
    "historyLimit": 50
  },
  "environments": [                 // P1：多环境变量
    { "id": "env-dev",  "name": "dev",  "vars": { "baseUrl": "http://127.0.0.1:8080", "token": "xxx" } },
    { "id": "env-prod", "name": "prod", "vars": { "baseUrl": "https://api.example.com", "token": "yyy" } }
  ],
  "activeEnvId": "env-dev",
  "scripts": [                      // 脚本库：集中维护可复用脚本（V1.5）
    {
      "id": "sc-uuid",
      "name": "部署前端",
      "content": "npm run build && echo done",
      "order": 1
    }
  ],
  "groups": [
    {
      "id": "g-uuid",
      "name": "环境检查",
      "color": "#409EFF",
      "collapsed": false,
      "order": 1,
      "buttons": [
        {
          "id": "b-uuid",
          "name": "检查登录接口",
          "color": "#67C23A",
          "icon": "🔍",                      // 可选，emoji 或图标名
          "confirm": false,                   // 执行前是否弹窗确认
          "showScript": true,                 // 运行输出中是否显示脚本内容（false = 只显示日志）
          "action": {
            "type": "curl",                   // curl | shell（V1 两种并存，P2 加 batch）
            "mode": "script",                 // script（原生脚本）| form（表单化，P2）
            "script": "curl -s -X POST {{baseUrl}}/login -H 'Authorization: Bearer {{token}}' -d '{\"user\":\"a\"}'",
            "timeoutSec": 30,
            "shell": "auto"                   // 可按按钮覆盖全局 shell
          },
          "order": 1
        },
        {
          "id": "b-uuid2",
          "name": "清理本机缓存",
          "color": "#F56C6C",
          "icon": "🧹",
          "confirm": true,
          "action": {
            "type": "shell",
            "mode": "script",
            "script": "rm -rf ~/cache/tmp && echo done",
            "timeoutSec": 60,
            "shell": "auto"
          },
          "order": 2
        },
        {
          "id": "b-uuid3",
          "name": "构建项目",
          "color": "#9B59B6",
          "icon": "📜",
          "confirm": false,
          "action": {
            "type": "script",                  // 引用脚本库条目，运行时解析内容
            "mode": "script",
            "script": "",                      // type=script 时为空
            "scriptId": "sc-uuid",             // 引用的脚本库条目 id
            "workdir": "D:\\projects\\web",    // 工作目录（空 = 不切换），支持 {{变量}}
            "args": "--release {{env}}",       // 位置参数（支持引号包裹含空格值），支持 {{变量}}
            "timeoutSec": 300,
            "shell": "auto"
          },
          "order": 3
        }
      ]
    }
  ]
}
```

**动作类型（action.type）设计**：
- `curl`：主打「script 模式」——直接粘贴 curl 命令（含多行、`| jq` 等管道），100% 兼容 curl 参数，支持从浏览器/Postman 复制的 curl 一键导入；P2 增加「form 模式」表单配置。
- `shell`：任意命令/脚本，与 curl 走同一执行链路（spawn 子进程 + 流式回传），只是 UI 上类型图标和校验不同。
- `script`（V1.5）：引用脚本库条目，可指定工作目录与位置参数执行。带参数/工作目录时后端将脚本落盘为临时文件再执行（bash 走 `$1`、PowerShell 走 `-File` + `$args`、CMD 走批处理 `%1`；bash 归一 LF、PowerShell 写 UTF-8 BOM、CMD 写 CRLF），用完即删；改脚本库内容对所有引用按钮即时生效。
- P2 预留 `batch`：按钮按顺序编排多个动作，前一步失败可中止。

**导入/导出格式（V1 留入口）**：
- 导出：`.quik.json`，内容为 `{ "kind": "quik-export", "version": 1, "exportedAt": "...", "groups": [...], "scripts": [...] }`，可选择导出整份或指定分组；脚本库仅导出被选中按钮引用到的条目；**默认不含环境变量**（避免泄露 token），可选包含。
- 导入：V1 为"整组追加"（不覆盖已有内容）；脚本按 id 合并（id 已存在时保留本地版本）；团队共享的合并/去重/冲突处理放 P2，但文件格式从一开始就按可合并设计。

## 5. 界面设计（V1）

```
┌──────────┬────────────────────────────────────────────┐
│  分组栏   │  [全部] [环境检查] [数据修复] ...   🔍搜索    │
│          ├────────────────────────────────────────────┤
│ ▼ 环境检查 │   ┌────────┐ ┌────────┐ ┌────────┐         │
│ ▶ 数据修复 │   │检查登录 │ │刷新缓存 │ │清缓存🖥 │  ＋    │
│ ▶ 临时    │   └────────┘ └────────┘ └────────┘         │
│          │   （卡片：白底，名称+图标+类型角标；自定义颜色    │
│ ＋ 新建组 │     作为强调色：图标底/悬停阴影/边框）          │
├──────────┴────────────────────────────────────────────┤
│  输出面板：最近一次执行 ▸ 状态(✓/✗) 耗时 退出码  [重跑]   │
│  ──────────────────────────────────────────           │
│  $ curl -s ...                                       │
│  {"code":0,"msg":"ok"}          （流式滚动，可复制）    │
└──────────────────────────────────────────────────────┘
   菜单栏/设置：导入配置、导出配置、设置（shell、历史条数、快捷键）
```

**视觉基调**（v0.4 调整）：浅灰画布 + 白色圆角浮层（主内容区 / 控制台），Element Plus 通过 CSS 变量统一主题（主色靛蓝 `#4e6ef2`、基础圆角 8px、弹窗圆角 14px）；按钮卡片改为白底，自定义颜色作为强调色（图标底、悬停阴影、边框），替代 v0.3 的整卡纯色背景。

交互要点：
- 点按钮卡片 = 立即执行；卡片右上角 `⋯` 或右键 = 编辑/复制/删除/拖拽排序。
- 长输出自动滚到底部，提供"停止"按钮 kill 子进程。
- 执行成功/失败在卡片上给短暂状态反馈（描边闪绿/红）。
- 关闭窗口 = 最小化到托盘（可配置为直接退出）；托盘菜单：显示主窗口 / 退出。
- 全局快捷键（默认 `Alt+Q`，可改）唤起/隐藏主窗口。

国际化（i18n）：
- vue-i18n（composition 模式），语言包 `src/i18n/zh-CN.ts` 与 `en-US.ts`，全部界面文案走 i18n key。
- 语言在设置页切换，持久化于 config.json `settings.language`（localStorage 缓存加速启动）。
- Element Plus 组件语言（日期、弹窗按钮等）通过 ElConfigProvider 随主语言同步切换。
- 新增语言只需增加一个语言包文件并在 `src/i18n/index.ts` 注册。

## 7. 风险与注意事项

1. **跨平台 shell 差异**（重点）：
   - 执行策略：`settings.defaultShell = auto` 时检测顺序为 **bash → powershell → cmd**（macOS/Linux 恒为 bash）。
   - Windows 无自带 bash，检测 Git Bash（常见路径 + `where bash`）；找不到则回退 PowerShell，此时脚本的管道/引号语法按 PowerShell 语义执行，需在 UI 提示当前生效 shell。
   - 建议文档提示 Windows 用户安装 Git Bash 以获得一致的脚本体验。
2. **Windows 编码坑**：cmd/PowerShell 默认 GBK，curl 返回 UTF-8 会中文乱码。对策：经 bash 执行时设 `LANG=C.UTF-8`；PowerShell 执行时前置 `chcp 65001`；输出按 UTF-8 解码，失败 fallback GBK。
3. **shell 元字符与引号**：从浏览器复制的 curl 常含单引号嵌套 JSON，经 bash 执行可保留原语义；编辑器提供"粘贴 curl 自动识别"减少手工修引号。
4. **安全边界**：按钮脚本 = 本机任意命令执行权限。定位为个人可信工具，配置文件不加锁；但危险按钮建议开启"执行前确认"；导入他人配置时可先预览脚本再导入。
5. **配置文件损坏**：写入采用「临时文件 + 原子替换」，并保留上一份 `.bak`。
6. **curl 版本差异**：Windows 自带 curl 基于 Schannel（TLS 参数与 OpenSSL 版略有差异）；设置页展示 `curl --version` 供排查。
7. **macOS 分发**：未签名 App 首次打开需右键→打开；后续若团队分发再买开发者证书做签名公证。
